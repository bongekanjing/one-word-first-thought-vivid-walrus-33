# One Word, First Thought

> **guddle** — *v.* to catch trout by groping with your bare hands under the stones of a stream; also, to muddle about and make a mess of something.

It is interesting because it is a verb with cold water and a fish in it — a vanished piece of daily life that survives only as this one strange, fumbling word.

## Run it

Node 22 runs the TypeScript directly; standard library only, no dependencies, no network.

```sh
node main.ts
# writes /output/entry.txt

MAKEFUN_OUTPUT_DIR=out node main.ts
# writes out/entry.txt — handy for local checks
```

The entry is written UTF-8 with no trailing newline. `main.ts` refuses to write a
word that is not a single token of 1..24 characters.
